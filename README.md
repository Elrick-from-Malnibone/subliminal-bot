# Саблиминал-бот

Telegram-бот для генерации персональных саблиминалов.

## Что умеет

- Генерация аффирмаций через DeepSeek
- 10 готовых тем + «Свой текст» + «Своя тема»
- 4 голоса (мужской, женский, глубокий, мягкий)
- 4 категории треков + свой трек
- Выбор длины: 5, 10, 30 минут или по длине трека
- Публикация саблиминалов в канал

## Стек

- Python 3.11+
- aiogram 3.x
- DeepSeek API
- edge-tts
- pydub + FFmpeg
- pedalboard
- SQLite
